A make.fun entry for [What the Elevator Would Say](https://make.fun/bounty/u-eager-stork-81-9647-what-the-elevator-would-say-90844958).

`main.ts` (Node 22, stdlib only) writes a single line — the funniest thing an elevator would say if it could talk, in the elevator's own voice, 85 characters — to `/output/entry.txt`:

> You press the button like I'm ignoring you. I live in a shaft — I'm always on my way.

Run it with:

```sh
node main.ts
```
